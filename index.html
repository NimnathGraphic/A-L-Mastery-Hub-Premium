යාන්ත්‍ර විද්‍යාව - A/L Physics Formulas

1. ඒකාකාර ත්වරණය යටතේ රේඛීය චලිතය

$$v = u + at$$ $$s = ut + \frac{1}{2}at^{2}$$ $$v^{2} = u^{2} + 2as$$ $$s = \left(\frac{u+v}{2}\right)t$$

2. නිව්ටන්ගේ චලිත නියම

දෙවන නියමය: $$F = ma$$ | $$F = \frac{\Delta p}{\Delta t}$$

තුන්වන නියමය: $$F_{AB} = -F_{BA}$$

3. ගම්‍යතාවය සහ ආවේගය

ගම්‍යතාවය: $$p = mv$$
ආවේගය: $$I = F \Delta t$$
ආවේග-ගම්‍යතා ප්‍රමේයය: $$I = \Delta p = m(v - u)$$
ගම්‍යතා සංස්ථිති නියමය: $$m_{1}u_{1} + m_{2}u_{2} = m_{1}v_{1} + m_{2}v_{2}$$

4. ඝර්ෂණය

ස්ථිතික ඝර්ෂණය: $$F_{s} \leq \mu_{s}R$$
ගතික ඝර්ෂණය: $$F_{k} = \mu_{k}R$$

5. කාර්යය, ශක්තිය සහ ක්ෂමතාව

කාර්යය: $$W = Fd \cos \theta$$
චාලක ශක්තිය: $$E_{k} = \frac{1}{2}mv^{2}$$
විභව ශක්තිය: $$E_{p} = mgh$$
ක්ෂමතාව: $$P = \frac{W}{t}$$ , $$P = Fv$$

6. වෘත්ත චලිතය

$$v = r\omega$$
කේන්ද්‍රභිසාරී ත්වරණය: $$a = \frac{v^{2}}{r} = r\omega^{2}$$
කේන්ද්‍රභිසාරී බලය: $$F = mr\omega^{2}$$

7. භ්‍රමණ චලිතය

$$\omega = \omega_{0} + \alpha t$$
$$\theta = \omega_{0}t + \frac{1}{2}\alpha t^{2}$$
$$\omega^{2} = \omega_{0}^{2} + 2\alpha \theta$$
ව්‍යාවර්තය: $$\tau = I\alpha$$ , කෝණික ගම්‍යතාවය: $$L = I\omega$$
භ්‍රමණ චාලක ශක්තිය: $$E = \frac{1}{2}I\omega^{2}$$

8. ද්‍රවස්ථිතික විද්‍යාව (පීඩනය)

ද්‍රව කඳක් මගින් ඇති කරන පීඩනය: $$P = h\rho g$$
උඩුකුරු තෙරපුම: $$U = V\rho g$$

9. ගුරුත්වාකර්ෂණය

විශ්ව ගුරුත්වාකර්ෂණ නියමය: $$F = G\frac{m_{1}m_{2}}{r^{2}}$$
ගුරුත්වාකර්ෂණ ක්ෂේත්‍ර තීව්‍රතාවය: $$g = G\frac{M}{r^{2}}$$

මූලික ත්‍රිකෝණමිතික අගයන්

සැලකිය යුතුයි: 90° හිදී $\tan$ අගය (එනම් $\frac{\sin(90^\circ)}{\cos(90^\circ)} = \frac{1}{0}$) බෙදීමට නොහැකි බැවින්, එය ගණිතයේදී "අර්ථ දක්වා නැත" (Undefined) ලෙස සලකනු ලබයි. එය අනන්තය ($\infty$) කරා ළඟා වේ.

1. මූලික ත්‍රිකෝණමිතික සර්වසාම්‍ය (Basic Identities)

මේවා තමයි ඕනෑම ත්‍රිකෝණමිතික ගාණක් සුළු කරද්දි පදනම විදිහට පාවිච්චි වෙන්නේ.

$$\sin^2 \theta + \cos^2 \theta = 1$$ $$1 + \tan^2 \theta = \sec^2 \theta$$ $$1 + \cot^2 \theta = \csc^2 \theta$$

2. සංයුක්ත කෝණ සමීකරණ (Compound Angle)

කෝණ දෙකක එකතුවක් හෝ අන්තරයක් තියෙනකොට ප්‍රසාරණය කරන්න මේවා පාවිච්චි කරනවා.

$$\sin(A \pm B) = \sin A \cos B \pm \cos A \sin B$$ $$\cos(A \pm B) = \cos A \cos B \mp \sin A \sin B$$ (මෙහි ලකුණු මාරු වන බව අවධානයට ගන්න: $+$ ඇති විට $-$ ද, $-$ ඇති විට $+$ ද වේ)

$$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A \tan B}$$

3. ගුණිත කෝණ සමීකරණ (Double Angle)

කෝණය දෙගුණයක් වෙලා තියෙන අවස්ථා වලදී තනි කෝණයකට හරවගන්න මේවා වැදගත්.

$$\sin 2\theta = 2 \sin \theta \cos \theta$$ $$\cos 2\theta = \cos^2 \theta - \sin^2 \theta = 2\cos^2 \theta - 1 = 1 - 2\sin^2 \theta$$ $$\tan 2\theta = \frac{2 \tan \theta}{1 - \tan^2 \theta}$$

4. අර්ධ කෝණ සමීකරණ ($t$-formulas)

$t = \tan\left(\frac{\theta}{2}\right)$ ලෙස ගත් විට,

$$\sin \theta = \frac{2t}{1 + t^2}$$ $$\cos \theta = \frac{1 - t^2}{1 + t^2}$$ $$\tan \theta = \frac{2t}{1 - t^2}$$

5. ත්‍රිත්ව කෝණ සමීකරණ (Triple Angle)

$3\theta$ කෝණයක් $\theta$ කෝණයක් බවට පත් කිරීමට:

$$\sin 3\theta = 3\sin \theta - 4\sin^3 \theta$$ $$\cos 3\theta = 4\cos^3 \theta - 3\cos \theta$$ $$\tan 3\theta = \frac{3\tan \theta - \tan^3 \theta}{1 - 3\tan^2 \theta}$$

6. ඓක්‍යයන් සහ අන්තර, ගුණිත බවට පත් කිරීම (Factor)

සයින් හෝ කොසයින් පද දෙකක එකතුවක් හෝ අඩු කිරීමක් ගුණිතයක් බවට පත් කරගන්න:

$$\sin C + \sin D = 2 \sin\left(\frac{C+D}{2}\right) \cos\left(\frac{C-D}{2}\right)$$ $$\sin C - \sin D = 2 \cos\left(\frac{C+D}{2}\right) \sin\left(\frac{C-D}{2}\right)$$ $$\cos C + \cos D = 2 \cos\left(\frac{C+D}{2}\right) \cos\left(\frac{C-D}{2}\right)$$ $$\cos C - \cos D = -2 \sin\left(\frac{C+D}{2}\right) \sin\left(\frac{C-D}{2}\right)$$

7. ගුණිත, ඓක්‍යයන් හෝ අන්තර බවට පත් කිරීම (Product to Sum)

$$2 \sin A \cos B = \sin(A+B) + \sin(A-B)$$ $$2 \cos A \sin B = \sin(A+B) - \sin(A-B)$$ $$2 \cos A \cos B = \cos(A+B) + \cos(A-B)$$ $$2 \sin A \sin B = \cos(A-B) - \cos(A+B)$$

8. සාධාරණ විසඳුම් (General Solutions)

$n \in \mathbb{Z}$ (එනම් $n$ යනු නිඛිලයකි)

$$\sin \theta = \sin \alpha \implies \theta = n\pi + (-1)^n \alpha$$ $$\cos \theta = \cos \alpha \implies \theta = 2n\pi \pm \alpha$$ $$\tan \theta = \tan \alpha \implies \theta = n\pi + \alpha$$

9. ත්‍රිකෝණ විසඳීම (Sine and Cosine Rules)

සාමාන්‍ය ත්‍රිකෝණයක $a, b, c$ පාද සහ ඊට සම්මුඛ $A, B, C$ කෝණ සඳහා:

Sine Rule (සයින් නීතිය):
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$ (මෙහි $R$ කියන්නේ ත්‍රිකෝණයේ පරිවෘත්තයේ අරයයි)

Cosine Rule (කොසයින් නීතිය):
$$a^2 = b^2 + c^2 - 2bc \cos A$$
