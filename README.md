# 📘 A/L Mastery Hub

A/L Mastery Hub යනු උසස් පෙළ (A/L) සිසුන් සඳහා ඔවුන්ගේ එදිනෙදා අධ්‍යයන කටයුතු, පන්ති කාලසටහන් සහ සූත්‍ර (Formulas) වඩාත් කාර්යක්ෂමව කළමනාකරණය කර ගැනීමට නිර්මාණය කරන ලද නවීන වෙබ් පාදක මෙවලමකි.

## 🚀 විශේෂාංග (Features)

* **Dashboard:** දෛනිකව පාඩම් කළ පැය ගණන Balmer Series වර්ණ අනුසාරයෙන් නිරීක්ෂණය කිරීම (Study Stars Tracker).
* **To-Do List:** දෛනික වැඩ කටයුතු කළමනාකරණය කිරීම සහ සම්පූර්ණ නොකළ වැඩ ස්වයංක්‍රීයව පසුදිනට යොමු කිරීම (Repeat Tasks).
* **Upcoming Work:** ඉදිරියට කිරීමට ඇති වැඩ විෂය අනුව වර්ග කර බැලීම.
* **Class Time Table:** පන්ති කාලසටහන් එකතු කිරීම සහ කළමනාකරණය.
* **Weekly Plan:** සතියේ දින අනුව විෂයන් සැලසුම් කිරීම.
* **Formulas Hub:** * භෞතික විද්‍යා සමීකරණ (Mechanics, Waves, etc.)
    * ත්‍රිකෝණමිතික සර්වසාම්‍ය සහ සමීකරණ.
    * අන්තර්ක්‍රියාකාරී ආවර්තිතා වගුව (Interactive Periodic Table).
* **Data Export:** මාසිකව අධ්‍යයන දත්ත PDF වාර්තාවක් ලෙස ලබාගැනීම.

## 🛠️ තාක්ෂණය (Technologies Used)

* HTML5
* CSS3 (Modern Design)
* JavaScript (Local Storage)
* MathJax (ගණිතමය සමීකරණ සඳහා)

## 📦 ස්ථාපනය සහ භාවිතය (How to Use)

1. මෙම Repository එක Clone කරගන්න.
2. `index.html` file එක ඕනෑම වෙබ් බ්‍රව්සරයකින් විවෘත කරන්න.
3. දත්ත සුරැකීම සඳහා වෙබ් බ්‍රව්සරයේ **Local Storage** භාවිතා වේ.

## 🔗 GitHub Pages හරහා Host කිරීම

1. ඔබේ Repository එකට ගොස් **Settings** වෙත යන්න.
2. **Pages** අංශය තෝරන්න.
3. **Build and deployment** යටතේ **Branch** එක `main` ලෙස තෝරා **Save** කරන්න.
4. විනාඩි කිහිපයකින් ඔබේ වෙබ් අඩවිය online live වනු ඇත.
